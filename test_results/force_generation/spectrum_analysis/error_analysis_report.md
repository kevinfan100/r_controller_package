# 電壓域與力域誤差分析報告

## 摘要

本報告分析了在 Force Generation 測試中觀察到的現象：
- **電壓域 (Vd-Vm)**：在零交叉點附近出現較大的誤差（最大 ~10%）
- **力域 (fd-fm)**：誤差分布相對均勻（最大 ~1%）

結論：**這是正常的物理特性，不是系統問題。**

---

## 1. 測試條件

| 參數 | 數值 |
|------|------|
| 測試信號 | 50 Hz 正弦波 |
| 力振幅 | 5 pN (X 軸) |
| 採樣率 | 100 kHz |
| 控制器頻寬 | 6 kHz |
| Rate Transition | Hardware 模式 (1600 Hz) |
| 分析範圍 | 0.6 - 1.2 s (穩態) |

## 3. 誤差來源分析

### 3.1 電壓誤差的時空分布

電壓誤差 |Vd - Vm| 與 Vd 大小的關係：

| Vd 範圍 | 平均誤差 % | 最大誤差 % | 說明 |
|---------|------------|------------|------|
| 0.0 - 0.1 V | 6.4% | 216% | **零交叉區域** |
| 0.1 - 0.2 V | 0.5% | 16% | 過渡區域 |
| 0.2 - 0.3 V | 2.2% | 3.6% | 正常區域 |
| 0.3 - 0.4 V | 1.1% | 1.6% | 正常區域 |
| 0.4 - 0.5 V | 0.6% | 0.8% | 峰值區域 |

**結論：電壓誤差主要發生在 Vd 接近零的時刻（零交叉點）**

### 3.2 誤差發生的物理機制

```
Error = Vd(t) - Vm(t)
      ≈ Vd(t) - Vd(t - τ)        [τ = 相位延遲]
      ≈ (dVd/dt) × τ             [一階近似]
```

- **相位延遲 τ**：來自控制器的因果性（約 1-20° @ 0-6 kHz）
- **斜率 dVd/dt**：在零交叉點最大，在峰值點為零
- **結果**：誤差在零交叉點最大

---

## 4. 為什麼力誤差比電壓誤差小？

### 4.1 力與電壓的非線性關係

Force Model 的物理關係：
```
f = g_H × Σ(v_i²)
```

力靈敏度（力對電壓的偏導數）：
```
∂f/∂v = 2 × g_H × v
```

**關鍵：力靈敏度與電壓成正比！**

### 4.2 力靈敏度效應

| 電壓值 | 電壓誤差 | 力靈敏度 (∂f/∂v) | 力誤差貢獻 |
|--------|----------|------------------|------------|
| 0.05 V (零交叉) | 0.04 V | 0.10 (低) | 0.004 (小) |
| 0.10 V | 0.04 V | 0.20 | 0.008 |
| 0.20 V | 0.04 V | 0.40 | 0.016 |
| 0.30 V | 0.04 V | 0.60 | 0.024 |
| 0.50 V (峰值) | 0.04 V | 1.00 (高) | 0.040 (大) |

### 4.3 圖解說明

```
電壓域：                           力域：

  Vd ─────╱╲─────                   fd ─────╱╲─────
         ╱  ╲                              ╱  ╲
        ╱    ╲                            ╱    ╲
  ─────╱      ╲─────                ─────╱      ╲─────
       ↑      ↑                          ↑      ↑
    零交叉  峰值                       零交叉  峰值
       │      │                          │      │
  誤差大  誤差小                     誤差小  誤差小*
       │      │                          │
       └──────┴──────────────────────────┘
                    │
                    ↓
         在零交叉點：
         • 電壓誤差大 (斜率最大)
         • 但力靈敏度低 (v ≈ 0)
         • 所以力誤差小！
```

*峰值處力誤差也小，因為電壓誤差本來就小

## 5. 數學推導

### 5.1 電壓誤差模型

假設 Vd 為正弦信號：
```
Vd(t) = A sin(ωt)
```

控制器相位延遲造成的誤差：
```
Vm(t) ≈ A sin(ωt - φ)

Error_v(t) = Vd - Vm
           = A[sin(ωt) - sin(ωt - φ)]
           ≈ A × φ × cos(ωt)         [φ << 1]
```

電壓誤差最大值發生在 cos(ωt) = ±1，即 **零交叉點**。

### 5.2 力誤差模型

力與電壓的關係（簡化為單通道）：
```
f = g × v²
```

力誤差：
```
Error_f = f_d - f_m
        = g × (Vd² - Vm²)
        = g × (Vd - Vm)(Vd + Vm)
        ≈ g × Error_v × 2Vd         [Vd ≈ Vm]
```

代入電壓誤差：
```
Error_f ≈ g × (Aφ cos(ωt)) × (2A sin(ωt))
        = g × A²φ × sin(2ωt)
```

**力誤差是 2 倍頻的正弦波！**

### 5.3 誤差比較

| 項目 | 電壓誤差 | 力誤差 |
|------|----------|--------|
| 波形 | cos(ωt) | sin(2ωt) |
| 最大值位置 | 零交叉點 (ωt = 0, π) | ωt = π/4, 3π/4 |
| 振幅 | Aφ | gA²φ |

在零交叉點 (ωt = 0)：
- 電壓誤差 = **最大** (Aφ)
- 力誤差 = **零** (sin(0) = 0)

這解釋了為什麼觀察到的力誤差分布比電壓誤差均勻。

## 6. 頻譜能量分析

### 6.1 Vd 頻譜能量分布

| 頻段 | 能量佔比 | 累積 |
|------|----------|------|
| 0 - 100 Hz | 97.4% | 97.4% |
| 100 - 500 Hz | 2.5% | 99.9% |
| 500 Hz - 6 kHz | 0.1% | 99.999% |
| > 6 kHz | **0.001%** | 100% |

### 6.2 結論

- 99.999% 的 Vd 能量在 Inner Loop 頻寬 (6 kHz) 以內
- 頻寬不是限制因素
- 誤差來自相位延遲，不是頻寬不足

---

## 7. 結論

### 7.1 觀察到的現象解釋

| 觀察 | 原因 |
|------|------|
| Vd-Vm 在零交叉誤差大 | 相位延遲 × 最大斜率 |
| fd-fm 誤差分布均勻 | 零交叉時力靈敏度低，補償了電壓誤差 |
| 力誤差比電壓誤差小 9 倍 | f ∝ v² 的非線性特性 |

### 7.2 系統評估

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  電壓追蹤誤差: 10.4% (max), 0.75% (RMS)                    │
│  力追蹤誤差:   1.14% (max), 0.35% (RMS)  ← 最終指標        │
│                                                             │
│  結論: 系統性能正常，力追蹤誤差 < 1.5% 符合預期            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 7.3 改善建議

| 優先級 | 項目 | 預期效果 |
|--------|------|----------|
| 低 | 增加 Inner Loop 頻寬 | 幾乎無效（能量已在頻寬內）|
| 中 | 減小控制器相位延遲 | 可減小電壓誤差 |
| 中 | 改善 inverse_model 諧波 | 可減小 P5/P6 異常 |
| - | 接受現狀 | 力誤差 1.14% 已經很好 |
