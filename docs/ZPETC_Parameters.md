# ZPETC 控制器參數整理

本文件整理 Zero Phase Error Tracking Controller (ZPETC) 的所有參數、推導關係及重要恆等式。

---

## 1. 系統常數（Plant Model）

離散時間受控體模型：
```
H(z⁻¹) = k_o * (1 + b·z⁻¹) / (1 - a₁·z⁻¹ - a₂·z⁻²)
```

| 參數 | 值 | 說明 |
|------|-----|------|
| `k_o` | 5.6695×10⁻⁴ | 受控體增益 |
| `b` | 0.9782 | 零點係數 |
| `a₁` | 1.934848 | 極點係數 1 |
| `a₂` | -0.935970 | 極點係數 2 |
| `T` | 1×10⁻⁵ s | 取樣時間 (100 kHz) |

---

## 2. 頻寬參數（輸入）

| 參數 | 說明 | 典型值 |
|------|------|--------|
| `fB_c` | 控制器頻寬 [Hz] | 300~1000 |
| `fB_e` | 估測器頻寬 [Hz] | 500~5000 |
| `fB_f` | 前饋濾波器頻寬 [Hz] | 1000~3000 |

---

## 3. 中間參數（從頻寬計算）

### 3.1 極點位置參數

| 參數 | 公式 | 說明 |
|------|------|------|
| `λ_f` | 0 (目前固定) | 前饋濾波器極點 |
| `λ_c` | exp(-fB_c × 2π × T) | 控制器極點 |
| `λ_e` | exp(-fB_e × 2π × T) | 估測器極點 |
| `β` | √(λ_e × λ_c) | 混合極點參數 |

### 3.2 控制增益

| 參數 | 公式 | 說明 |
|------|------|------|
| `k_c` | (1 - λ_c) / (1 + b) | 控制增益 |
| `b_c` | b × k_c | 零點增益 |
| `k_u` | k_c / k_o | 控制輸出增益 |

---

## 4. 重要恆等式 ⭐

以下恆等式在分析控制器穩定性時非常重要：

### 4.1 基本恆等式

```
λ_c + k_c = 1 - b_c
```

**推導**：
```
λ_c + k_c = λ_c + (1 - λ_c)/(1 + b)
          = [λ_c(1 + b) + (1 - λ_c)] / (1 + b)
          = [λ_c + λ_c·b + 1 - λ_c] / (1 + b)
          = (1 + λ_c·b) / (1 + b)

1 - b_c = 1 - b·k_c
        = 1 - b·(1 - λ_c)/(1 + b)
        = [(1 + b) - b(1 - λ_c)] / (1 + b)
        = [1 + b - b + b·λ_c] / (1 + b)
        = (1 + λ_c·b) / (1 + b)  ✓
```

### 4.2 第二恆等式

```
k_c + b_c = 1 - λ_c
```

**推導**：
```
k_c + b_c = k_c + b·k_c
          = k_c(1 + b)
          = [(1 - λ_c)/(1 + b)] × (1 + b)
          = 1 - λ_c  ✓
```

### 4.3 恆等式總結

| 恆等式 | 等價形式 |
|--------|----------|
| `λ_c + k_c = 1 - b_c` | 特徵方程式係數等價 |
| `k_c + b_c = 1 - λ_c` | 極點配置等價 |
| `k_c(1 + b) = 1 - λ_c` | 定義關係 |
| `b_c = b × k_c` | 定義關係 |

## 5. 控制器方程式

### 5.1 前饋濾波器

```
v_f[k] = λ_f·v_f[k-1] + k_ff·{b·v_d[k] + (1 - λ_c·b)·v_d[k-1] - λ_c·v_d[k-2]}
```

其中：
```
k_ff = (1 - λ_f) / [(1 - λ_c)(1 + b)]
```

當 λ_f = 0 時，k_ff = 1 / [(1 - λ_c)(1 + b)]

### 5.2 誤差計算

```
δv_f[k] = v_f[k] - (λ_c + k_c)·v_f[k-1] - b_c·v_f[k-2]
δv[k] = v_f[k] - v_m[k]
```

### 5.3 估測器（Disturbance Observer）

```
δv̂[k] = λ_c·δv̂[k-1] + δv_f[k] + L₁·{δv[k-1] - δv̂[k-1]}
ŵ₁[k] = (1+β)·ŵ₁[k-1] - β·ŵ₂[k-1] + L₂·{δv[k-1] - δv̂[k-1]}
ŵ₂[k] = ŵ₁[k-1] + L₃·{δv[k-1] - δv̂[k-1]}
```

### 5.4 估測器增益（極點配置於 λ_e）

```
L₁ = λ_c + (1 + β) - 3λ_e

L₂ = [b(λ_e - 1)³ - β(b + 1)(β² - 3βλ_e + β + 3λ_e² - 3λ_e + 1)] / [k_c(b + 1)(b + β)]

L₃ = -[β + b + βb - 3βλ_e - 3bλ_e + bβ² + 3bλ_e² + β² + λ_e³ - 3βbλ_e] / [k_c(b + 1)(b + β)]
```

### 5.5 控制律

**穩定版本（目前使用）**：
```
δv_c[k] = δv[k] - ŵ₁[k]                    ← 使用實際測量值 δv
u_c[k] = (1 - b_c)·u_c[k-1] + b_c·u_c[k-2] + k_u·{δv_c[k] - a₁·δv_c[k-1] - a₂·δv_c[k-2]}
```

**PDF 版本（不穩定）**：
```
δv_c[k] = δv̂[k] - ŵ₁[k]                   ← 使用估測值 δv̂
u_c[k] = λ_c·u_c[k-1] + (k_c + b_c)·u_c[k-2] + k_u·{δv_c[k] - a₁·δv_c[k-1] - a₂·δv_c[k-2]}
```

**重要發現**：由於恆等式 `λ_c + k_c = 1 - b_c` 和 `k_c + b_c = 1 - λ_c`，兩個版本的 u_c 係數實際上相同！

| 穩定版本係數 | PDF 版本係數 | 恆等關係 |
|-------------|-------------|---------|
| `1 - b_c` | `λ_c` | λ_c = 1 - b_c - k_c，但 λ_c + k_c = 1 - b_c |
| `b_c` | `k_c + b_c` | k_c + b_c = 1 - λ_c，但需要驗證 |

等等，讓我重新檢驗：
- 穩定版本：`(1-b_c)·u_c[k-1] + b_c·u_c[k-2]`
- PDF 版本：`λ_c·u_c[k-1] + (k_c+b_c)·u_c[k-2]`

由於 `λ_c + k_c = 1 - b_c`，所以 `λ_c = 1 - b_c - k_c ≠ 1 - b_c`（除非 k_c = 0）

**所以兩個版本的係數確實不同！**

## 6. 特徵方程式分析

### 6.1 δv_f 的特徵方程式

```
δv_f[k] = v_f[k] - (λ_c + k_c)·v_f[k-1] - b_c·v_f[k-2]
```

特徵方程式：`z² - (λ_c + k_c)z - b_c = 0`

由恆等式 λ_c + k_c = 1 - b_c，等價於：
```
z² - (1 - b_c)z - b_c = 0
```

### 6.2 u_c 的特徵方程式

**穩定版本**：
```
u_c[k] = (1 - b_c)·u_c[k-1] + b_c·u_c[k-2] + ...
```
特徵方程式：`z² - (1 - b_c)z - b_c = 0` ← **與 δv_f 相同！**

**PDF 版本**：
```
u_c[k] = λ_c·u_c[k-1] + (k_c + b_c)·u_c[k-2] + ...
```
特徵方程式：`z² - λ_c·z - (k_c + b_c) = 0`

由恆等式 k_c + b_c = 1 - λ_c，等價於：
```
z² - λ_c·z - (1 - λ_c) = 0
```

### 6.3 極點比較

| 版本 | 特徵方程式 | 極點 |
|------|-----------|------|
| 穩定版本 (δv_f & u_c) | z² - (1-b_c)z - b_c = 0 | z₁ = 1, z₂ = -b_c |
| PDF 版本 (u_c) | z² - λ_c·z - (1-λ_c) = 0 | z₁ = 1, z₂ = -(1-λ_c)/1 = λ_c - 1 |

**關鍵觀察**：
- 穩定版本極點：z = 1 和 z = -b_c（|b_c| < 1，穩定）
- PDF 版本極點：z = 1 和 z = λ_c - 1（當 λ_c ≈ 1 時，接近 0）

兩者都有一個極點在 z = 1（積分器），這是控制器設計的特性。

## 7. 穩定性問題分析

### 7.1 問題描述

當將控制律中的 `δv` 改為 `δv̂` 時，控制器發散。

### 7.2 數值驗證

以 fB_c = 500 Hz 為例：

| 參數 | 值 |
|------|-----|
| λ_c | 0.969072 |
| k_c | 0.015634 |
| b_c | 0.015293 |

**係數比較**：

| 版本 | u_c[k-1] 係數 | u_c[k-2] 係數 |
|------|--------------|--------------|
| 穩定版本 | 1 - b_c = 0.9847 | b_c = 0.0153 |
| PDF 版本 | λ_c = 0.9691 | k_c + b_c = 0.0309 |
| **差異** | **+0.0156 (= k_c)** | **-0.0156 (= -k_c)** |

**特徵方程式極點**：

| 版本 | 極點 | 極點模 |
|------|------|--------|
| 穩定版本 | z = 1, z = -0.0153 | 都在單位圓內 |
| PDF 版本 | z = 1, z = -0.0309 | 都在單位圓內 |

**結論**：兩個版本的 u_c 特徵方程式極點都在單位圓內，所以問題不在於 u_c 係數本身。

### 7.3 真正的問題：δv vs δv̂

**穩定版本**：
```
δv_c[k] = δv[k] - ŵ₁[k]
        = (v_f[k] - v_m[k]) - ŵ₁[k]
```
這裡 v_m[k] 是實際測量值，包含真實的系統響應。

**PDF 版本**：
```
δv_c[k] = δv̂[k] - ŵ₁[k]
```
δv̂[k] 是 Observer 的輸出，會有估測誤差和相位延遲。

### 7.4 可能的不穩定原因

1. **閉迴路互動**：
   - 當使用 δv̂ 時，控制器輸出 u 會影響 v_m
   - v_m 變化影響 δv = v_f - v_m
   - δv 變化影響 Observer 估測 δv̂
   - δv̂ 變化又回到控制器
   - 這形成一個額外的反饋迴路，可能導致不穩定

2. **相位延遲累積**：
   - Observer 估測 δv̂ 相對於真實 δv 有相位延遲
   - 在高頻時，累積的相位延遲可能超過相位裕度
   - 導致閉迴路不穩定

3. **分離原理失效**：
   - 分離原理（Separation Principle）假設估測器和控制器可以獨立設計
   - 但當控制律使用估測值而非真實值時，這個假設可能不成立
   - 特別是在離散時間系統中，延遲效應更加顯著

### 7.5 根本原因分析 ⭐

經過深入分析，發現不穩定的根本原因：

**系統中的積分器 (z=1 極點)**：

1. **Controller 積分器**：
   - 特徵方程式：`(z-1)(z+bc) = 0` → z=1 極點
   - 作用：消除穩態誤差

2. **Disturbance Observer 積分器**：
   - ŵ1, ŵ2 子系統特徵方程式：`(z-1)(z-β) = 0` → z=1 極點
   - 作用：追蹤緩慢變化的干擾

**穩定版本的信號路徑**：
```
主反饋路徑：vm[k] → δv[k] → δvc[k] → Controller → u[k]
              ↑                                      ↓
              └──────────── Plant ←─────────────────┘

Observer 路徑：δv[k] → Observer → ŵ1[k] → (減去) → δvc[k]
```
- Observer 的 z=1 極點只影響 ŵ1 的估測
- 不在主反饋路徑中，不會造成雙重積分問題

**PDF 版本的信號路徑**：
```
主反饋路徑：vm[k] → δv[k] → Observer → δv̂[k] → δvc[k] → Controller → u[k]
              ↑                                                        ↓
              └───────────────────── Plant ←──────────────────────────┘
```
問題：
1. Observer 的動態（含 z=1）直接進入主反饋路徑
2. vm[k] 經過 Observer 後變成 vm[k-1]，額外延遲一個 step
3. 兩個 z=1 極點（Observer + Controller）在同一迴路中串聯

**結論**：
使用 δv（直接測量）而非 δv̂（估測值）是正確的設計選擇：
1. 保持對測量值 vm[k] 的即時響應（無額外延遲）
2. 避免 Observer 的 z=1 極點進入主控制迴路
3. 確保閉迴路穩定性

## 8. 數值範例

以 fB_c = 500 Hz, fB_e = 500 Hz 為例：

```matlab
T = 1e-5;
b = 0.9782;

lambda_c = exp(-500 * 2 * pi * T) = 0.9691
lambda_e = exp(-500 * 2 * pi * T) = 0.9691
beta = sqrt(0.9691 * 0.9691) = 0.9691

k_c = (1 - 0.9691) / (1 + 0.9782) = 0.0156
b_c = 0.9782 * 0.0156 = 0.0153

% 驗證恆等式
lambda_c + k_c = 0.9691 + 0.0156 = 0.9847
1 - b_c = 1 - 0.0153 = 0.9847  ✓

k_c + b_c = 0.0156 + 0.0153 = 0.0309
1 - lambda_c = 1 - 0.9691 = 0.0309  ✓
```

## 9.5 實驗驗證 (2026-01-27)

### 測試條件
- Simulink 模型：main_system.slx
- 測試信號：正弦波 (Amplitude = 0.1 V)
- 測試頻率：100 Hz ~ 2000 Hz
- fB_e = 2 × fB_c

### 測試結果

| fB_c [Hz] | fB_e [Hz] | delta_v | delta_v_hat |
|-----------|-----------|---------|-------------|
| 500       | 1000      | ✓ 穩定   | ✓ 穩定       |
| 3000      | 6000      | ✓ 穩定   | ✓ 穩定       |
| 5000      | 10000     | ✓ 穩定   | ✗ 發散       |
| 7000      | 14000     | ✓ 穩定   | ✗ 發散       |
| 10000     | 20000     | ✓ 穩定   | ✗ 發散       |

### 關鍵發現

1. **臨界點**：delta_v_hat 版本在 fB_c ≥ 5000 Hz 時開始不穩定

2. **delta_v 版本始終穩定**：即使在 fB_c = 10000 Hz 的極端情況下

3. **原始程式碼驗證**：
   - git 歷史顯示初始提交 (4ac0167) 就使用 `delta_v`
   - `delta_v_hat` 版本從未被實作

4. **Implementation_control_law.png 分析**：
   - 圖中 Equation 8：`δvc[k] = δv̂[k] - ŵ1[k] + L1·Sx[k-1]`
   - 注意有額外補償項 `+ L1·Sx[k-1]`
   - 此補償項可能是為了穩定 δv̂ 版本，但未在程式碼中實作

### 結論

使用 `delta_v`（直接測量）是正確且經過驗證的設計選擇。
