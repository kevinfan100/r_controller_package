# ZOH 與線性插值延遲推導

本文檔使用 Convolution Integral 推導 Zero-Order Hold (ZOH) 與因果線性插值的等效延遲。

---

## 0. 整體邏輯概述

### 0.1 我們要解決什麼問題？

```
問題：ZOH 和線性插值各造成多少延遲？

      離散樣本              重建系統              連續輸出
      x[n] ──────────────→ [  ?  ] ──────────────→ y(t)
      (在 n×Ts 取得)        ZOH 或               (有延遲)
                           線性插值
```

### 0.2 解決思路（三步驟）

```
┌─────────────────────────────────────────────────────────────────────┐
│  Step 1: 找到脈衝響應 h(t)                                           │
│  ─────────────────────────────────────────────────────────────────  │
│                                                                     │

│                                                                     │
│       輸入              系統                輸出                     │
│       x[0]=1    →    [重建系統]    →    h(t) = ?                    │
│                                                                     │
│  意義：h(t) 描述「一個樣本的能量如何在時間上分佈」                     │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
                                 ↓
┌─────────────────────────────────────────────────────────────────────┐
│  Step 2: 計算 h(t) 的「質心」                                        │
│  ─────────────────────────────────────────────────────────────────  │
│                                                                     │
│  問：h(t) 的能量「平均」在什麼時刻？                                  │
│                                                                     │
│              ∫ t × h(t) dt       加權平均時刻                        │
│        τ = ─────────────────  = ──────────────                      │
│                ∫ h(t) dt           總權重                            │

│                                                                     │

│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 0.3 為什麼「質心」代表延遲？

**物理直覺**：

```
想像 h(t) 是一根桿子的質量分佈：

ZOH 的 h(t)：矩形
    ████████
    ████████
----+--------+----→ t
    0   ↑   Ts
      質心在 Ts/2

線性插值的 h(t)：三角形
        /\
       /  \
      /    \
-----+------+-----→ t
     0  ↑  Ts  2Ts
      質心在 Ts
```

**質心 = 重心位置 = 平均作用時刻 = 等效延遲**

### 0.4 數學上的對應關係

```
┌──────────────────┬────────────────────────────────────────────────┐
│     概念          │              公式                              │
├──────────────────┼────────────────────────────────────────────────┤
│ 輸出信號          │ y(t) = Σ x[n] × h(t - n×Ts)                   │
│                  │        （所有樣本貢獻的疊加）                    │
├──────────────────┼────────────────────────────────────────────────┤
│ 脈衝響應          │ h(t) = y(t) 當輸入 x[n] = δ[n]                │
│                  │        （單一樣本的輸出）                       │
├──────────────────┼────────────────────────────────────────────────┤
│ 等效延遲          │ τ = ∫t×h(t)dt / ∫h(t)dt                       │
│                  │        （h(t) 的質心位置）                      │
├──────────────────┼────────────────────────────────────────────────┤
│ 延遲步數          │ d = τ / Ts                                    │
│                  │        （延遲幾個採樣週期）                      │
└──────────────────┴────────────────────────────────────────────────┘
```

### 0.5 完整範例：線性插值

```
Step 1: 找 h(t)
────────────────
輸入 x[0]=1, 其餘=0，用線性插值公式計算輸出：

  t ∈ [0, Ts):   y = 0×(1-t/Ts) + 1×(t/Ts) = t/Ts        ↗ 上升
  t ∈ [Ts, 2Ts): y = 1×(1-δ/Ts) + 0×(δ/Ts) = (2Ts-t)/Ts  ↘ 下降
  其他:           y = 0

得到 h(t) = 三角形，峰值在 t=Ts


Step 2: 算質心
────────────────
分子 = ∫ t×h(t) dt = ∫[0,Ts] t×(t/Ts) dt + ∫[Ts,2Ts] t×(2Ts-t)/Ts dt
     = Ts²/3 + 2Ts²/3
     = Ts²

分母 = ∫ h(t) dt = 三角形面積 = (1/2)×(2Ts)×1 = Ts

τ = Ts² / Ts = Ts


Step 3: 延遲步數
────────────────
d = τ / Ts = Ts / Ts = 1.0 步


結論：線性插值延遲 1 個採樣週期
```

### 0.6 為什麼不直接看 h(t) 的峰值位置？

```
問：h(t) 峰值在 t=Ts，為什麼延遲不直接就是 Ts？

答：峰值只是一個點，但 h(t) 在整個區間 [0, 2Ts) 都有值。
    系統的「真正」延遲是所有時刻的加權平均，也就是質心。

    對於對稱的三角形，質心剛好在峰值位置，所以 τ = Ts。
    但對於非對稱的 h(t)，質心和峰值可能不同。
```

### 0.7 驗證：質心公式的正確性

質心公式來自物理學的質心定義：

```
         Σ (位置 × 質量)       連續版本      ∫ t × h(t) dt
質心 = ─────────────────  ───────────→  ─────────────────
            Σ 質量                          ∫ h(t) dt
```

對於 h(t)：
- h(t) 代表「在時刻 t 的權重/強度」
- t × h(t) 代表「時刻 t 的加權貢獻」
- 積分後除以總權重 = 平均時刻 = 延遲

## 延遲計算方法：脈衝響應的質心

對於任意脈衝響應 h(t)，等效延遲定義為其**質心（Center of Mass）**：

```
        ∫ t × h(t) dt
  τ = ─────────────────
          ∫ h(t) dt
```

這代表脈衝響應的「平均作用時間」，等同於系統的群延遲（Group Delay）。

## 1. Zero-Order Hold (ZOH)

### 1.1 脈衝響應定義

```
h_ZOH(t) = | 1,  當 0 ≤ t < Ts
           | 0,  其他
```

圖示：
```
h(t)
  1 |████████|
    |████████|
    |████████|
  0 +--------+------→ t
    0        Ts
```

### 1.2 分母計算：總面積

```
∫ h_ZOH(t) dt = ∫[0 to Ts] 1 dt = Ts
```

### 1.3 分子計算：一階矩

```
∫ t × h_ZOH(t) dt = ∫[0 to Ts] t × 1 dt

                  = [t²/2] 從 0 到 Ts

                  = Ts²/2
```

### 1.4 等效延遲

```
τ_ZOH = (Ts²/2) / Ts = Ts/2
```

### 1.5 延遲步數

```
d_ZOH = τ_ZOH / Ts = (Ts/2) / Ts = 0.5 步
```

## 2. 因果線性插值 (Causal Linear Interpolation)

### 2.1 因果性說明

在即時系統中，時刻 t ∈ [m×Ts, (m+1)×Ts) 時：
- 可用樣本：x[m]（剛收到）、x[m-1]（上一週期收到）
- 不可用：x[m+1]（尚未到達）

因此只能用 x[m-1] 和 x[m] 進行插值。

### 2.2 因果線性插值的輸出公式

定義 δ = t - m×Ts，其中 0 ≤ δ < Ts

在時刻 t ∈ [m×Ts, (m+1)×Ts) 的輸出為：

```
y(t) = x[m-1] × (1 - δ/Ts) + x[m] × (δ/Ts)
```

展開：
```
y(t) = x[m-1] × (1 - δ/Ts) + x[m] × (δ/Ts)

     = x[m-1] - x[m-1]×(δ/Ts) + x[m]×(δ/Ts)

     = x[m-1] + (x[m] - x[m-1]) × (δ/Ts)
```

這是 x[m-1] 和 x[m] 之間的線性內插。

### 2.3 脈衝響應推導

#### 2.3.1 為什麼要找 h(t)？

**線性非時變系統（LTI System）的基本性質**：

任何 LTI 系統都可以完全由其**脈衝響應 h(t)** 來描述。
一旦知道 h(t)，就能計算任意輸入的輸出。

#### 2.3.2 離散到連續的重建問題

我們的問題是：

```
輸入：離散樣本序列 x[n]，在時刻 n×Ts 取得
輸出：連續信號 y(t)

問題：如何從 x[n] 重建 y(t)？
```

#### 2.3.3 Convolution 公式的意義

**公式**：
```
y(t) = Σ x[n] × h(t - n×Ts)
       n
```

**逐項解釋**：

| 項目 | 意義 |
|------|------|
| x[n] | 第 n 個採樣值（在時刻 n×Ts 取得） |
| h(t) | 脈衝響應：單一樣本對輸出的「影響函數」 |
| h(t - n×Ts) | h(t) 延遲到時刻 n×Ts（對齊到第 n 個樣本的時刻） |
| x[n] × h(t - n×Ts) | 第 n 個樣本對輸出的貢獻（加權後的影響函數） |
| Σ | 所有樣本貢獻的總和 |

**圖示說明**：

```
離散樣本：
x[n]:     x[0]    x[1]    x[2]    x[3]
           |       |       |       |
時間軸: ---+-------+-------+-------+--→ t
           0      Ts     2Ts     3Ts

每個樣本產生一個「響應」：

x[0] 的貢獻：x[0] × h(t)
               ___
              /   \
           --+-----+--→ t
             0

x[1] 的貢獻：x[1] × h(t - Ts)
                    ___
                   /   \
           -------+-----+--→ t
                  Ts

x[2] 的貢獻：x[2] × h(t - 2Ts)
                         ___
                        /   \
           ------------+-----+--→ t
                      2Ts

總輸出 y(t) = 所有貢獻疊加
```

#### 2.3.4 為什麼這個公式是對的？

**線性性**：系統是線性的，所以各樣本的貢獻可以直接相加。

**非時變性**：系統是非時變的，所以：
- 樣本在 t=0 產生響應 h(t)
- 樣本在 t=Ts 產生響應 h(t-Ts)（相同形狀，只是延遲）
- 樣本在 t=n×Ts 產生響應 h(t-n×Ts)

**因此**：任意輸入序列 x[n] 的輸出就是所有單位脈衝響應的加權疊加。

#### 2.3.5 如何找到 h(t)？

**方法**：令輸入為單位脈衝

```
x[n] = δ[n] = | 1,  當 n = 0
              | 0,  當 n ≠ 0
```

代入 Convolution 公式：

```
y(t) = Σ x[n] × h(t - n×Ts)
       n

     = x[0] × h(t - 0) + x[1] × h(t - Ts) + x[2] × h(t - 2Ts) + ...

     = 1 × h(t) + 0 × h(t - Ts) + 0 × h(t - 2Ts) + ...

     = h(t)
```

**結論**：當輸入是單位脈衝時，輸出就是 h(t)。

所以我們只需要：
1. 假設輸入 x[0]=1，其餘 x[n]=0
2. 用系統的輸出公式計算 y(t)
3. 這個 y(t) 就是 h(t)

---

**情況 1：t ∈ [0, Ts)，即 m = 0**

```
δ = t - 0 = t

y(t) = x[-1] × (1 - t/Ts) + x[0] × (t/Ts)
     = 0 × (1 - t/Ts) + 1 × (t/Ts)
     = t/Ts

所以 h(t) = t/Ts，當 0 ≤ t < Ts
```

---

**情況 2：t ∈ [Ts, 2Ts)，即 m = 1**

```
δ = t - Ts

y(t) = x[0] × (1 - (t-Ts)/Ts) + x[1] × ((t-Ts)/Ts)
     = 1 × (1 - (t-Ts)/Ts) + 0 × ((t-Ts)/Ts)
     = 1 - (t-Ts)/Ts
     = (Ts - t + Ts)/Ts
     = (2Ts - t)/Ts

所以 h(t) = (2Ts - t)/Ts，當 Ts ≤ t < 2Ts
```

---

**情況 3：t ∈ [2Ts, 3Ts)，即 m = 2**

```
δ = t - 2Ts

y(t) = x[1] × (1 - (t-2Ts)/Ts) + x[2] × ((t-2Ts)/Ts)
     = 0 × (...) + 0 × (...)
     = 0

所以 h(t) = 0，當 t ≥ 2Ts
```

---

**情況 4：t < 0**

```
因果系統，t < 0 時無輸出

h(t) = 0，當 t < 0
```

---

### 2.4 脈衝響應總結

```
h_linear(t) = | t/Ts,             當 0 ≤ t < Ts      (上升段)
              | (2Ts - t)/Ts,     當 Ts ≤ t < 2Ts    (下降段)
              | 0,                其他
```

### 2.5 脈衝響應圖示

```

    |       /  \        峰值在 t = Ts
    |      /    \
    |     /      \
  0 +----+--------+----→ t
         0   Ts   2Ts

    |<-->|  上升段：h = t/Ts
         |<---->|  下降段：h = (2Ts-t)/Ts
```

```

### 2.7 與非因果線性插值的比較

**非因果（理想）線性插值**：可以使用 x[m] 和 x[m+1]

```
h_ideal(t) = | 1 + t/Ts,    當 -Ts ≤ t < 0
             | 1 - t/Ts,    當 0 ≤ t < Ts
             | 0,           其他

圖示：
h(t)
  1 |    /\
    |   /  \
    |  /    \
    | /      \
  0 +--------+----→ t
   -Ts   0   Ts

質心 τ = 0（零延遲，但不可實現）
```

**因果線性插值**：只能使用 x[m-1] 和 x[m]

```
h_causal(t) = h_ideal(t - Ts)  ← 整體右移 Ts

圖示：
h(t)
  1 |        /\
    |       /  \
    |      /    \
    |     /      \
  0 +----+--------+----→ t
         0   Ts   2Ts

質心 τ = Ts（延遲一個週期）
```

**結論**：因果線性插值 = 理想線性插值 + 延遲 Ts

### 2.3 分母計算：總面積

三角形面積 = (1/2) × 底 × 高

```
∫ h_linear(t) dt = (1/2) × (2Ts) × 1 = Ts
```

或分段積分：
```
∫[0 to Ts] (t/Ts) dt + ∫[Ts to 2Ts] (2 - t/Ts) dt

= [t²/(2Ts)] 從 0 到 Ts  +  [2t - t²/(2Ts)] 從 Ts 到 2Ts

= Ts/2 + [(4Ts - 2Ts) - (2Ts - Ts/2)]

= Ts/2 + [2Ts - 1.5Ts]

= Ts/2 + Ts/2

= Ts
```

### 2.4 分子計算：一階矩

分段計算：

**上升段 [0, Ts]：**
```
∫[0 to Ts] t × (t/Ts) dt = (1/Ts) × ∫[0 to Ts] t² dt

                         = (1/Ts) × [t³/3] 從 0 到 Ts

                         = (1/Ts) × (Ts³/3)

                         = Ts²/3
```

**下降段 [Ts, 2Ts]：**
```
∫[Ts to 2Ts] t × (2 - t/Ts) dt = ∫[Ts to 2Ts] (2t - t²/Ts) dt

                                = [t² - t³/(3Ts)] 從 Ts 到 2Ts

                                = [(4Ts² - 8Ts³/(3Ts)) - (Ts² - Ts³/(3Ts))]

                                = [(4Ts² - 8Ts²/3) - (Ts² - Ts²/3)]

                                = [4Ts² - 8Ts²/3 - Ts² + Ts²/3]

                                = [3Ts² - 7Ts²/3]

                                = [9Ts²/3 - 7Ts²/3]

                                = 2Ts²/3
```

**總和：**
```
∫ t × h_linear(t) dt = Ts²/3 + 2Ts²/3 = Ts²
```

### 2.5 等效延遲

```
τ_linear = Ts² / Ts = Ts
```

### 2.6 延遲步數

```
d_linear = τ_linear / Ts = Ts / Ts = 1.0 步
```

## 4. 物理意義

### 4.1 ZOH 延遲 = 0.5 步

```
時間軸：
    x[m-1]      x[m]       x[m+1]
      |          |           |
      +----●-----+-----●-----+----→ t
     (m-1)Ts    mTs    (m+1)Ts

ZOH 在區間 [mTs, (m+1)Ts) 輸出恆定值 x[m]：
  - 區間起點使用 x[m]：延遲 = 0
  - 區間終點使用 x[m]：延遲 = Ts
  - 平均延遲 = Ts/2 = 0.5 步
```

### 4.2 線性插值延遲 = 1.0 步

```
時間軸：
    x[m-1]      x[m]       x[m+1]
      |          |           |
      +----●-----+-----●-----+----→ t
     (m-1)Ts    mTs    (m+1)Ts
           \    /
            \  /  ← 用這兩點插值
             \/

線性插值在區間 [mTs, (m+1)Ts) 使用 x[m-1] 和 x[m]：
  - 實際重建的是 [(m-1)Ts, mTs] 區間的信號
  - 但輸出時間是 [mTs, (m+1)Ts]
  - 整體延遲 = Ts = 1.0 步
```

```
H_ZOH(jω) = Ts × sinc(ωTs/2π) × exp(-jωTs/2)
                 \_________/     \________/

```

H_linear(jω) = Ts × sinc²(ωTs/2π) × exp(-jωTs)

                      幅度項          延遲項

```
